# 뉴스 댓글 진위 판별 분석 프로젝트

## 프로젝트 개요
본 프로젝트는 네이버 뉴스 댓글 데이터를 수집하여, 댓글이 인간이 작성한 것인지 봇(자동 생성)인지 판단하는 머신러닝 모델 개발을 목표로 합니다.  
기존의 ‘죽은 인터넷 이론’을 참고하여, 댓글 패턴 및 특징 분석에 기반한 진위 판별 알고리즘을 설계하고자 합니다.

## 데이터 수집 과정

### 1. 뉴스 기사 목록 크롤링
- 네이버 정치 섹션(https://news.naver.com/section/100)에서 최신 뉴스 기사 URL을 수집  
- `data-imp-url` 속성을 활용하여 원문 기사 URL 획득  
- 페이지네이션 및 속도 제한 적용으로 안정적 데이터 수집 구현

### 2. 개별 뉴스 기사 본문 및 댓글 크롤링
- 각 뉴스 기사에서 제목, 본문 내용 크롤링  
- 네이버 공식 댓글 API를 통해 댓글 데이터 수집  
- 댓글이 없는 기사는 데이터베이스에 저장하지 않음  
- 댓글 페이지가 여러 개일 경우, `moreParam.next`를 활용해 다음 페이지 댓글도 수집

### 3. 데이터 저장
- MySQL 데이터베이스에 뉴스 기사와 댓글을 분리된 테이블로 저장  
- SQLAlchemy ORM 및 Core 활용하여 효율적이고 안정적인 DB 처리 구현  
- 중복 저장 방지 및 트랜잭션 관리 적용

## 기술 스택
- Python 3.10
- Requests, BeautifulSoup4 (웹 크롤링)  
- SQLAlchemy (DB ORM)  
- MySQL (데이터 저장)  
- Asyncio (비동기 처리 및 속도 제한)  

## 향후 계획
- 수집된 댓글 데이터 전처리 및 특징 추출  
- 댓글 텍스트 기반 봇/휴먼 판별 머신러닝 모델 개발  
- 모델 성능 평가 및 개선  
- 웹 서비스 또는 API 형태로 진위 판별 기능 배포
